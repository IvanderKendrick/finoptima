### 6️⃣ Optimization Page (Mean-Variance Optimization)

* Data aset diambil dari **Assets Page**
* User memilih aset dan memasukkan bobot atau sistem membagi bobot sederhana
* Input tambahan (jika diperlukan):

  * Risiko
  * Kovarians / korelasi (boleh manual)

#### Perhitungan MVO:

Expected Return Portofolio:
E(Rₚ) = Σ (wᵢ × E(Rᵢ))

Varians Portofolio:
σₚ² = Σ Σ (wᵢ × wⱼ × Cov(Rᵢ, Rⱼ))

Risiko Portofolio:
σₚ = √(σₚ²)

Implementasi boleh sederhana / mock, yang penting:

* rumus digunakan
* hasil logis
* sesuai use case

Output:

* Bobot optimal aset
* Expected return portofolio
* Risiko portofolio

Grafik (opsional):

* Efficient frontier
* Diagram alokasi aset

Setiap hasil optimasi **disimpan otomatis ke History**.
